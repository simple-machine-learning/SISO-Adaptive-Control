Soil ecology: moisture respiration with delay¶

Python model: plant_models.soil_moisture_respiration_with_delay

Description¶

Delayed-input variant of soil_moisture_respiration.

The transport delay is represented by an 4-stage cascaded lag (Erlang transport approximation) with mean delay input_delay_sec. This keeps the plant in finite-dimensional ODE form while producing a substantially delayed, smooth actuator command.

Model equations¶

State variables¶

The augmented state consists of the physical-model state vector \(\mathbf{x}_{p}(t)\) and the delay-chain states \(z_1(t),\ldots,z_{n_d}(t)\):

\[\mathbf{x}(t)=\begin{bmatrix}\mathbf{x}_{p}(t)^{\mathsf T}&z_1(t)&\cdots&z_{n_d}(t)\end{bmatrix}^{\mathsf T}.\]

This model uses the same physical equations as Soil ecology: moisture-controlled respiration, but the commanded input is passed through an \(n_d\)-stage first-order lag cascade. Let \(u_0=u(t)\) and let \(z_i(t)\) denote the state of delay stage \(i\).

\[\begin{split}\begin{aligned} \tau_s &= \frac{\tau_d(t)}{n_d}, \\ \dot{z}_1(t) &= \frac{u(t)-z_1(t)}{\tau_s}, \\ \dot{z}_i(t) &= \frac{z_{i-1}(t)-z_i(t)}{\tau_s},\qquad i=2,\ldots,n_d. \end{aligned}\end{split}\]

Static and auxiliary relations¶

No additional static relation is required; the input enters directly in the state equations.

State equations¶

The base plant receives \(u_d(t)=z_{n_d}(t)\) instead of \(u(t)\). Thus the complete state is the physical state of the base model augmented by \([z_1(t),\ldots,z_{n_d}(t)]^\mathsf{T}\). The cascade is a finite-dimensional approximation of the configured input delay.

Output equation¶

The controlled input and output used by the identification and control algorithms are defined explicitly as

\[\begin{split}\begin{aligned} u(t)\in\mathbb{R}\quad\text{(undelayed irrigation command)},\\ y(t)=\Delta R_{\mathrm{CO_2}}(t)=R_{\mathrm{CO_2}}(t)-R_{\mathrm{CO_2},0}. \end{aligned}\end{split}\]

The function default_params() returns the combined default parameter object used by the GUI and simulation. Initial state:

def initial_state(par):
    x0 = np.asarray(base.initial_state(par), dtype=float)
    return np.concatenate((x0, np.zeros(int(par.delay_order), dtype=float)))

Algebraic outputs:

def algebraic_outputs(chi, par):
    x, z = _split(chi, par)
    out = dict(base.algebraic_outputs(x, par))
    out["effective_input"] = float(z[-1]) if len(z) else 0.0
    out["input_delay_sec"] = float(par.input_delay_sec)
    return out

ODE right-hand side:

def rhs(t, chi, u, par):
    x, z = _split(chi, par)
    order = max(1, int(par.delay_order))
    tau_stage = max(float(par.input_delay_sec) / order, 1.0e-12)
    dz = np.empty(order, dtype=float)
    source = float(u)
    for i in range(order):
        dz[i] = (source - z[i]) / tau_stage
        source = z[i]
    dx = np.asarray(base.rhs(t, x, float(z[-1]), par), dtype=float)
    return np.concatenate((dx, dz))
