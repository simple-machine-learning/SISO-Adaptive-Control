Bioprocess: photobioreactor pH / CO2¶

Python model: plant_models.photobioreactor_ph_co2

Description¶

Photobioreactor: pH control by CO2 dosing with light-driven uptake. state vector \(\mathbf{x}\) = [C_CO2, X, Q_CO2, I, pH_filter,0,0], y2=pH-pH0.

Model equations¶

State variables¶

The physical state vector used by the model is

\[\mathbf{x}(t)=[C(t),\,X(t),\,Q(t),\,I(t),\,pH(t)]^\mathsf{T}.\]

Static and auxiliary relations¶

The auxiliary quantities are

\[\begin{split}\begin{aligned} Q_{\mathrm{cmd}}(t)&=Q_0+k_Q\tanh(u(t)) \\ I_{\mathrm{target}}(t)&=I_0+A_I\sin\!\left(\dfrac{2\pi t}{T_I}\right) \\ r_p(t)&=v_{\max}X(t)\dfrac{I(t)}{K_I+I(t)}\dfrac{C(t)}{K_C+C(t)} \\ C_g(t)&=k_gQ(t) \\ pH_{\mathrm{eq}}(t)&=pH_0-\beta_{pH}(C(t)-C_0) \\ \mu(t)&=\mu_{\max}\dfrac{I(t)}{K_I+I(t)}\dfrac{C(t)}{K_C+C(t)} \end{aligned}\end{split}\]

State equations¶

The implemented continuous-time dynamics are

\[\begin{split}\begin{aligned} \dot{C}(t)&=k_La(C_g(t)-C(t))-r_p(t) \\ \dot{X}(t)&=(\mu(t)-k_d)X(t) \\ \dot{Q}(t)&=\dfrac{Q_{\mathrm{cmd}}(t)-Q(t)}{\tau_Q} \\ \dot{I}(t)&=\dfrac{I_{\mathrm{target}}(t)-I(t)}{0.5} \\ \dot{pH}(t)&=\dfrac{pH_{\mathrm{eq}}(t)-pH(t)}{\tau_{pH}} \end{aligned}\end{split}\]

Output equation¶

The controlled input and output used by the identification and control algorithms are defined explicitly as

\[\begin{split}\begin{aligned} u(t)\in\mathbb{R}\quad\text{(CO_2 dosing command)},\\ y(t)=\Delta pH(t)=pH(t)-pH_0. \end{aligned}\end{split}\]

Implementation reference¶

Initial state:

def initial_state(par): return np.array([par.C0,par.X0,par.Q0,par.I0,par.pH0,0,0],float)

Algebraic outputs:

def algebraic_outputs(chi,par):
    C,X,Q,I,pH=chi[:5]
    return {"CO2":C,"biomass":X,"CO2_flow":Q,"light":I,"pH":pH,"pH_deviation":pH-par.pH0}

ODE right-hand side:

def rhs(t,chi,u,par):
    C,X,Q,I,pH=chi[:5]; Qcmd=par.Q0+par.Q_gain*np.tanh(u)
    Itarget=par.I0+par.light_amp*np.sin(2*np.pi*t/par.light_period)
    photo=par.uptake_max*X*(I/(par.K_I+I))*(C/(par.K_C+C))
    Cgas=par.C_gas_gain*Q
    pHeq=par.pH0-par.beta_pH*(C-par.C0)
    mu=par.mu_max*(I/(par.K_I+I))*(C/(par.K_C+C))
    return np.array([par.kla*(Cgas-C)-photo,(mu-par.k_decay)*X,
                     (Qcmd-Q)/par.tau_Q,(Itarget-I)/0.5,(pHeq-pH)/par.tau_pH,0,0],float)
