Model equations¶

State variables¶

The physical state vector used by the model is

\[\mathbf{x}(t)=[T(t),\,f(t)]^\mathsf{T}.\]

Static and auxiliary relations¶

The auxiliary quantities are

\[\begin{split}\begin{aligned} f_{\mathrm{cmd}}(t)&=\operatorname{clip}\!\left(f_0-k_f\tanh(u(t)),0,1\right) \\ P_\ell(t)&=P_{\ell,0}\exp\!\left(\operatorname{clip}(\alpha_\ell(T(t)-T_0),-5,5)\right) \\ Q_c(t)&=\left(G_p+G_f[f(t)]_+\right)(T(t)-T_a) \end{aligned}\end{split}\]

State equations¶

The implemented continuous-time dynamics are

\[\begin{split}\begin{aligned} \dot{T}(t)&=\dfrac{P_w+P_\ell(t)-Q_c(t)}{C_T} \\ \dot{f}(t)&=\dfrac{f_{\mathrm{cmd}}(t)-f(t)}{\tau_f} \end{aligned}\end{split}\]

Output equation¶

The controlled input and output used by the identification and control algorithms are defined explicitly as

\[\begin{split}\begin{aligned} u(t)\in\mathbb{R}\quad\text{(signed thermal command)},\\ y(t)=\Delta T(t)=T(t)-T_0. \end{aligned}\end{split}\]

Parameter implementation¶

The editable default parameters are defined in apps/simulated/plant_models/cpu_thermal_fan.py. They are fields of PlantParams near the beginning of that file. The function default_params() returns the default parameter object used by the GUI and simulation. Implementation reference¶

Initial state:

def initial_state(par): return np.array([par.temperature_nom, par.fan_nom, 0.0], float)

Algebraic outputs:

def algebraic_outputs(chi, par):
    T, fan = chi[:2]
    leakage = par.leakage_power*np.exp(par.leakage_alpha*(T-par.temperature_nom))
    cooling = (par.passive_conductance+par.fan_conductance*fan)*(T-par.ambient)
    return {"temperature_deviation": T-par.temperature_nom, "temperature": T,
            "fan_speed": fan, "chip_power": par.workload_power+leakage,
            "cooling_power": cooling}

ODE right-hand side:

def rhs(t, chi, u, par):
    T, fan = chi[:2]
    fan_cmd = np.clip(par.fan_nom-par.fan_gain*np.tanh(float(u)), 0.0, 1.0)
    leakage = par.leakage_power*np.exp(np.clip(par.leakage_alpha*(T-par.temperature_nom),-5.0,5.0))
    cooling = (par.passive_conductance+par.fan_conductance*max(fan,0.0))*(T-par.ambient)
    dT = (par.workload_power+leakage-cooling)/par.thermal_capacity
    return np.array([dT, (fan_cmd-fan)/par.tau_fan, 0.0], float)
