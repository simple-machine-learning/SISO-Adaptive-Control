Network: router fluid queue with large delay¶

Python model: plant_models.network_router_fluid_queue_with_large_delay

Description¶

Delayed-input variant of network_router_fluid_queue.

The transport delay is represented by an 4-stage cascaded lag (Erlang transport approximation) with mean delay input_delay_sec. This keeps the plant in finite-dimensional ODE form while producing a substantially delayed, smooth actuator command.

Model equations¶

State variables¶

The augmented state consists of the physical-model state vector \(\mathbf{x}_{p}\) and the delay-chain states \(z_1(t),\ldots,z_{n_d}(t)\):

\[\mathbf{x}(t)=\begin{bmatrix}\mathbf{x}_{p}(t)^{\mathsf T}&z_1(t)&\cdots&z_{n_d}(t)\end{bmatrix}^{\mathsf T}.\]

The connection between the controlled input, the ODE states, and the controlled output is explicit:

\[u(t) \longrightarrow z_1(t),\ldots,z_{n_d}(t) \longrightarrow u_d(t)=z_{n_d}(t) \longrightarrow r(t) \longrightarrow q(t) \longrightarrow y(t)=\Delta q(t)=q(t)-q_0.\]

Static and auxiliary relations¶

The physical router states are queue occupancy \(q(t)\) and admitted traffic rate \(r(t)\). The delayed command \(u_d(t)\) enters the admitted-rate command

\[\begin{split}\begin{aligned} r_{\mathrm{cmd}}(t)&=C+k_r\tanh(u_d(t)), \\ s(q(t))&=C\left[s_0+(1-s_0)\left(1-\exp\!\left(-\frac{[q(t)]_+}{q_s}\right)\right)\right]. \end{aligned}\end{split}\]

State equations¶

The delayed command is generated by an \(n_d\)-stage first-order lag cascade. With \(z_0=u(t)\),

\[\begin{split}\begin{aligned} \tau_s &= \frac{\tau_d(t)}{n_d}, \\ \dot{z}_1(t) &= \frac{u(t)-z_1(t)}{\tau_s}, \\ \dot{z}_i(t) &= \frac{z_{i-1}(t)-z_i(t)}{\tau_s},\qquad i=2,\ldots,n_d, \\ u_d(t) &= z_{n_d}(t). \end{aligned}\end{split}\]

The implemented physical dynamics are

\[\begin{split}\begin{aligned} \dot{q}(t)&=r(t)-s(q(t))-k_\ell q(t), \\ \dot{r}(t)&=\frac{r_{\mathrm{cmd}}(t)-r(t)}{\tau_r}. \end{aligned}\end{split}\]

Output equation¶

The controlled output shown in the top table is not an additional ODE state. It is computed algebraically from \(q(t)\):

\[\begin{split}\begin{aligned} y(t)=\Delta q(t)&=q(t)-q_0, \\ r_{\mathrm{in}}(t)&=r(t), \\ r_{\mathrm{out}}(t)&=s(q(t)), \\ \tau_q(t)&=\frac{q(t)}{\max(r_{\mathrm{out}}(t),\varepsilon)}. \end{aligned}\end{split}\]

def algebraic_outputs(chi, par):
    x, z = _split(chi, par)
    out = dict(base.algebraic_outputs(x, par))
    out["effective_input"] = float(z[-1]) if len(z) else 0.0
    out["input_delay_sec"] = float(par.input_delay_sec)
    return out

ODE right-hand side:

def rhs(t, chi, u, par):
    x, z = _split(chi, par)
    order = max(1, int(par.delay_order))
    tau_stage = max(float(par.input_delay_sec) / order, 1.0e-12)
    dz = np.empty(order, dtype=float)
    source = float(u)
    for i in range(order):
        dz[i] = (source - z[i]) / tau_stage
        source = z[i]
    dx = np.asarray(base.rhs(t, x, float(z[-1]), par), dtype=float)
    return np.concatenate((dx, dz))
