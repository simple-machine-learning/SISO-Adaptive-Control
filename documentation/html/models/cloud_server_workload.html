Input-output connection¶

The controlled input \(u(t)\) enters the capacity command \(c_{\mathrm{cmd}}=c_0+k_c\tanh(u)\). This command drives the state \(c(t)\) through \(\dot c=(c_{\mathrm{cmd}}-c)/\tau_c\). The allocated capacity \(c(t)\) changes the service rate \(s(x,c)\), which drives the backlog state \(x(t)\). The reported response-time proxy and controlled output are

\[\tau(t)=k_L x(t),\qquad y(t)=\Delta\tau(t)=\tau(t)-k_Lx_0=k_L(x(t)-x_0).\]

Hence the complete signal path is

\[u(t)\;\longrightarrow\;c_{\mathrm{cmd}}(t)\;\longrightarrow\;c(t) \;\longrightarrow\;s(x(t),c(t))\;\longrightarrow\;x(t) \;\longrightarrow\;y(t)=\Delta\tau(t).\]

Model equations¶

State variables¶

The physical state vector used by the model is

\[\mathbf{x}(t)=[x(t),\,c(t)]^\mathsf{T}.\]

Static and auxiliary relations¶

The auxiliary quantities are

\[\begin{split}\begin{aligned} c_{\mathrm{cmd}}(t)&=c_0+k_c\tanh(u(t)) \\ s(x(t),c(t))&=\dfrac{[c(t)]_+[x(t)]_+}{K_s+[x(t)]_+} \\ [r]_+&=\max(r,0) \end{aligned}\end{split}\]

State equations¶

The implemented continuous-time dynamics are

\[\begin{split}\begin{aligned} \dot{x}(t)&=\lambda-s(x(t),c(t))-k_a x(t) \\ \dot{c}(t)&=\dfrac{c_{\mathrm{cmd}}(t)-c(t)}{\tau_c} \end{aligned}\end{split}\]

Output equation¶

The implementation clips the backlog derivative at zero when \(x(t) \leq 0\) and the unconstrained value of \(\dot{x}(t)\) is negative.

The response-time proxy and controlled output are

\[\begin{split}\begin{aligned} \tau(t)&=k_Lx(t),\\ y(t)&=\Delta\tau(t)=\tau(t)-\tau_0=k_L(x(t)-x_0). \end{aligned}\end{split}\]

The controlled input and output used by the identification and control algorithms are defined explicitly as

\[\begin{split}\begin{aligned} u(t)\in\mathbb{R}\quad\text{(compute-capacity command)},\\ y(t)=\Delta\tau(t)=\tau(t)-\tau_0=k_L\bigl(x(t)-x_0\bigr). \end{aligned}\end{split}\]

Implementation reference¶

Initial state:

def initial_state(par): return np.array([par.backlog_nom, par.service_nom, 0.0], float)

Algebraic outputs:

def algebraic_outputs(chi, par):
    x, c = chi[:2]
    service = c*x/(par.half_saturation+max(x,0.0))
    latency = par.latency_gain*x
    return {"latency_deviation": latency-par.latency_gain*par.backlog_nom,
            "backlog": x, "allocated_capacity": c, "service_rate": service,
            "response_time": latency}

ODE right-hand side:

def rhs(t, chi, u, par):
    x, c = chi[:2]
    c_cmd = par.service_nom + par.service_gain*np.tanh(float(u))
    service = max(c,0.0)*max(x,0.0)/(par.half_saturation+max(x,0.0))
    dx = par.arrival_rate-service-par.abandonment*x
    if x <= 0.0 and dx < 0.0: dx = 0.0
    return np.array([dx, (c_cmd-c)/par.tau_capacity, 0.0], float)
