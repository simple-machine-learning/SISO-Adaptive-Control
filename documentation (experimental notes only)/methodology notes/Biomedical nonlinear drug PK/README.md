# Biomedical nonlinear drug PK

**System class:** Nonlinear pharmacokinetic dynamics  

Shows an MRAC example using compact HONU structures. The operating range and training excitation are particularly important for nonlinear dose-response dynamics.

These figures are representative examples and practical starting points, not universal optimum settings. Recheck sampling, training-data coverage, model order, learning parameters, controller penalties, constraints, and spectral-radius diagnostics for each new operating range.
