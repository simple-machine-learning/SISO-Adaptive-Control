# Process bidirectional-pump nonlinear tank

**System class:** Asymmetric nonlinear process  

Compares several MRAC and MPC configurations on a nonlinear tank. The examples demonstrate that LNU can be an effective baseline while QNU may better capture curvature and asymmetric behavior.

These figures are representative examples and practical starting points, not universal optimum settings. Recheck sampling, training-data coverage, model order, learning parameters, controller penalties, constraints, and spectral-radius diagnostics for each new operating range.
